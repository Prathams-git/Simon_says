# 🎮 Simon Says Game

A simple and interactive **Simon Says Memory Game** built using HTML, CSS, and JavaScript.

The game tests your memory by generating a sequence of colored buttons. You have to remember and repeat the sequence correctly to reach higher levels.

## ✨ Features

- Interactive color-based memory game.
- Random color sequence generation.
- Increasing difficulty with each level.
- Visual flash effects for game and user interactions.
- Score tracking.
- High score saved using Local Storage.
- Simple and clean user interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic and functionality.
- **Local Storage** – Saving the highest score.

## 🎯 How to Play

1. Open the game in your browser.
2. Press any keyboard key to start.
3. Watch the color sequence carefully.
4. Click the buttons in the same sequence.
5. Each successful round increases your level.
6. One wrong click ends the game.
7. Try to beat your highest score!

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Prathams-git/Simon_says.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
